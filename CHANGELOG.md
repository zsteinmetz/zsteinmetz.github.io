# CHANGELOG

## Unreleased
- The `list` sections (homepage news and `sections`-type pages) now support an optional `limit` key, capping the number of rendered entries independently of how many the source TOML file contains (e.g., `limit = 5` in the `[[sections]] id = "news"` block of `content/about.toml`); omitting the key keeps the previous behavior of showing all entries. Documented in `README.md`.
- Every publication on the Publications page (and the homepage's selected publications) now shows a "DOI" link button (https://doi.org/<doi>, with a localized tooltip/aria-label: "Open publication via DOI"/"Publikation über DOI öffnen") next to the abstract and BibTeX actions, using the `doi` field from `content/publications.bib`, and the "Cited by N" text became a badge linking to the publication's OpenAlex work page (matched by DOI, falling back to title matching, with the BibTeX DOI used when no OpenAlex record exists). Publications without a DOI or without metrics simply omit the respective element.
- Fixed site-owner highlighting in publication author lists for abbreviated author names: `buildNameVariants` in `src/lib/bibtexParser.ts` now also generates initial-based variants of the configured `author.name`, so "Dr. Zacharias Steinmetz" highlights both "Zacharias Steinmetz" and abbreviated forms like "Steinmetz, Z." (rendered as "Z. Steinmetz") in `publications.bib`. Middle names are abbreviated along with the first name ("Kilian G. J. Kenngott" matches "K. G. J. Kenngott").
- Renamed the profile page to match its documentation: `content/profile.toml` is now `content/cv.toml` and the page is served at `/cv` instead of `/profile`, as `docs/cv.md` and `README.md` already described. The navigation entry keeps its visible label ("Profile"/"Profil"); only the internal target and URL changed, along with the link to it from the homepage bio. External links to the old `/profile` URL will now 404 (static export, no redirects).
- The site name in the fixed header is now hidden on the homepage while the profile name under the profile picture is on screen (the profile card is sticky, so this is tracked with an IntersectionObserver rather than a scroll offset), fading in once the visitor scrolls past it; the element stays mounted so the menu keeps its right-aligned position. All other pages keep the header title at all times. The browser tab title is unaffected.
- Fixed mixed-font rendering of diacritics: the self-hosted Lora, IBM Plex Sans, and IBM Plex Mono files were Latin-only subsets, so Czech characters (Š, ž, ř, č…) in author names and Greek letters (μ, α, β, δ, ψ) in abstracts silently fell back to a system font. All five woff2 files were re-subset from the full variable fonts (via the google/fonts repository; IBM Plex Mono from the current IBM/plex release, which also adds thin/narrow spaces) to cover Basic Latin, Latin-1, Latin Extended A+B, Greek, general punctuation, and math symbols (− ≤ ≥ ≈), with IBM Plex Sans's unused `wdth` axis pinned to 100 to keep the file small. Total font payload: ~307 KB (was ~189 KB). Known upstream limits: Lora has no Greek glyphs (irrelevant in practice — Greek only appears in body text, which uses IBM Plex Sans), and IBM Plex Mono has no Greek, so Greek letters in the on-page BibTeX snippet still fall back to the system monospace font.
- Rewrote 30 of the 31 publication `description` teasers in `content/publications.bib`: most previously restated the article title (several were verbatim copies) and now summarize the key approach or finding from each abstract instead (e.g. methods, effect sizes, outcomes). The Open Specy 2021 teaser was kept.
- Dropped the unused `language`, `shorttitle`, and `url` fields from `content/publications.bib`: none are rendered by the site (the CV “Publisher link” button was redundant with the DOI link shown next to it, which every affected entry has).
- Cleaned the publication abstracts: stripped glued structured-abstract headings from `SteinmetzPlastic2022` (Background/Method/Results/Discussion) and `MeyerAgricultural2025` (Background/Aim/Methods/Results/Conclusions), fixed the glued word “sizedependent” → “size-dependent” in `HeinzeVertical2024`, corrected en dashes mistakenly used as minus signs in unit exponents (“min–1”, “μg kg–1”), and converted the remaining 48 LaTeX `\%` escapes in abstracts to literal percent signs.
- Synced `content/publications.bib` with a fresh Zotero export: keywords now come from the (cleaned) publisher keyword lists in the export — case duplicates, MeSH-style fragments, `PDF`, and broken entries were dropped; entries without keywords in the export keep their curated tags. Bibliographic fixes from the export: `MeyerAgricultural2025` gained volume 188, issue 6, pages 964–976 and both ISSNs; `BuchmannImpact2025` now uses the correct article number 19422 instead of pages 1–17; the Ondruch et al. 2017 co-author name was corrected to “Jiřę Kučerík”-style diacritics (Kučerík, Jiří); LaTeX math (`$\alpha$`/`$\beta$`) in the Cortez et al. 2026 abstract was converted to Unicode. Export-only fields (month, urldate, file, copyright, langid, ids, shorttitle, publisher) were not imported; `pdf`/`supp` links were kept.
- Added a new `sections` page type: any page can now be composed of `[[sections]]` blocks exactly like the homepage — `markdown` (with hero extraction), `highlight` (tinted cards), `publications` (`filter`/`limit`), `list` (news source), and `card` (inline card items with `title`, `subtitle`, `date`, Markdown `content`, `tags`, and optional teaser images, like `card` pages) — rendered in order under the page title/description. The section processing logic was extracted to `src/lib/sections.ts` and is shared with the homepage, whose section rendering now goes through the same `SectionRenderer` (no visual changes); the card grid was likewise extracted into a reusable `CardGrid` component used by both `card` pages and `card` sections. The Teaching page was rebuilt on the new type: the teaching philosophy now lives in the page description, the three teaching principles are shortened into three stacked highlight cards, and the inverted-classroom format is summarized in one sentence in the markdown body. Documented in `README.md`.
- The CV publications section now supports `show_complete = false` in the `[publications]` block of `content/<page>.toml` (default `true`): it renders only the featured publications and omits the complete bibliography grouped by type — useful when the full searchable list already lives on the `/publications` page. Documented in `docs/cv.md`; enabled on the `/profile` and `/research` pages.
- Replaced the demo content with the real site content for Zacharias Steinmetz (English): the main menu is now Home · Profile · Research · Teaching, with Publications moved to a subpage reachable via the homepage "View All" link and the research/profile pages. `content/profile.toml` (narrative CV at `/profile`), `content/research.toml` (research profile, projects, selected publications, and data & software at `/research`), and `content/teaching.toml` + `content/teaching.md` (teaching concept at `/teaching`) replace the placeholder CV, services, and teaching pages; the demo `content/cv.toml`, `content/services.toml`, and the German demo counterparts were removed. `content/publications.bib` now contains the real bibliography (31 entries, LaTeX accents converted to Unicode, HTML entities cleaned, `abbr`/`urldate` dropped, `selected`/`keywords`/`description` curation added), and `site.url` is set to `https://zsteinmetz.de` so sitemap.xml and robots.txt are generated.
- Fixed the shared Markdown link renderer: react-markdown's AST `node` prop no longer leaks into the DOM as an invalid `node="[object Object]"` attribute, and internal site links (e.g. `/research`) now open in the same tab while external links keep opening in a new tab with `rel="noopener noreferrer"`.
- Fixed site-owner highlighting in publication author lists: common academic title prefixes (e.g. "Dr.", "Prof. Dr.") in `content/config.toml`'s `author.name` are now ignored when matching against author names in `publications.bib`, so "Dr. Zacharias Steinmetz" correctly highlights "Zacharias Steinmetz" in publication author lists.
- The footer's "Last updated" date is now computed automatically at build time from the latest git commit touching `content/`, `content_<locale>/`, or `public/` (with a file-mtime fallback when git is unavailable, and mtime taking precedence while there are uncommitted changes), and is localized per site language instead of using hand-formatted per-locale strings. The manually maintained `last_updated` key in `[site]` (and in `content_<locale>/config.toml`) is deprecated, ignored, and removed from the bundled content. Also fixes the footer falling back to the visitor's current date when no value was configured. Documented in `README.md`.
- Added a general "hide the heading" convention: setting `title = ""` (an explicitly empty string) on homepage sections (`markdown`, `publications`, `list`, `highlight`) or on page configs (`text`, `card`, `publication`, `cv`) hides the on-page heading while everything else renders unchanged; omitting the key keeps the previous behavior (localized defaults for homepage sections, configured titles for pages). The Selected Publications section keeps its "View All" link (right-aligned) when its heading is hidden, and the browser tab title of dynamic pages falls back to the site title when the page heading is hidden. Documented in `README.md`.
- Added `highlight` sections for easy-to-grasp overview cards (e.g., research areas): a new `type = "highlight"` section in page TOML files (such as `content/about.toml`) renders a responsive grid of tinted cards with a colored top bar, a serif heading, and short Markdown content. `columns` controls how many cards appear per row (1–4, default 3), and `color` customizes the box color either as a theme token (`accent` — the copper default, `primary`, `success`, `warning`, `info`, `error`, all light/dark-mode aware) or as any raw CSS color applied as a soft tint; a per-item `color` overrides the section color. The cards deliberately stand out from the plain white card boxes while staying within the theme. The same `[highlights]` block can also be added to `content/cv.toml` (rendered after the academic profile). Item content supports `{{ section.key }}` config variables. Documented in `README.md` and `docs/cv.md`.
- The email tooltip on the homepage profile now shows the plain email address (with `@`) instead of the ` (at) ` spelling, since the address is public via the imprint and repository anyway.
- Added variables in Markdown: Markdown files (page `source` files such as `content/imprint.md`) and string values in page TOML files (e.g., card item content) now support `{{ section.key }}` placeholders that are replaced at build time with the corresponding value from `content/config.toml` (merged with `content_<locale>/config.toml` for localized pages), so details like the email address only need to be defined once. Array items are addressable by index (`social.location_details.0`), unknown variables are left unchanged with a build-time warning, and BibTeX files are not substituted. The imprint templates now use `{{ author.name }}` and `{{ social.email }}`. Documented in `README.md`.
- Added automatic `sitemap.xml` and `robots.txt` generation: setting `url` in the `[site]` section of `content/config.toml` emits a sitemap listing the homepage, navigation pages, `[[subpages]]` targets, and `[legal]` slugs (with trailing slashes matching the site's links), plus a `robots.txt` allowing all crawlers and pointing to the sitemap. `site.url` is also used as the `metadataBase` so OpenGraph metadata resolves to absolute URLs. Both files are skipped gracefully when `url` is unset. Documented in `README.md`.
- Replaced the "Built with PRISM 🚀" footer link with configurable links to legal pages: set `imprint` and `privacy` slugs in the new `[legal]` section of `content/config.toml` (leave blank or delete a key to hide a link). Footer labels are localized (Imprint/Impressum, Privacy Policy/Datenschutzerklärung). Added imprint and privacy policy page templates (including German versions) with placeholder legal details, and the "Built with PRISM" reference now lives in the imprint template. Documented in `README.md`.
- Added support for pages outside the main navigation: new `[[subpages]]` entries in `content/config.toml` render a page at `/{target}` (content from `content/<target>.toml`) without adding it to the nav menu, so it can be linked from any page or the footer. `generateStaticParams` now registers navigation pages, `[[subpages]]` targets, and `[legal]` slugs. Documented in `README.md`.
- Code cleanup with no visual or behavioral changes: removed unused dependencies (`lightningcss` and the linux-only `lightningcss-linux-x64-gnu` binary, both already provided transitively by Tailwind), unused glass-morphism styles and custom line-height properties, the unused `.no-print` / `text-balance` / `text-pretty` utilities, and redundant `Publication`/`Author` type fields (unused fields such as `arxivId`, `impactFactor` and `awards` were removed; `keywords`, `status`, `venue`, `location` and `pdfUrl` were kept for future use, and the duplicate `tags` field was merged into `keywords` for BibTeX consistency). Also removed a redundant favicon `<link>` (Next.js metadata already emits it), deduplicated the publications-with-metrics loading on dynamic pages, and simplified BibTeX month parsing.
- Added optional teaser images for card items: each `card` page item can now set `image = "/my-image.png"` (a path inside `public/`) and optionally `imageAlt = "..."` for alt text. The image is rendered as a responsive thumbnail beside the card content (stacking above it on mobile), following the same layout pattern as publication preview images. Cards without an image are rendered exactly as before. Documented in `README.md`.
- Redesigned the navigation language and theme toggles to blend in with the menu links: both are now borderless, transparent buttons instead of boxed controls. The language toggle shows a globe icon plus a compact locale code (EN/DE) with click-to-cycle switching (replacing the dropdown menu), and the theme toggle resolves the system preference to a sun/moon icon and toggles between light and dark with a single click (replacing the system/light/dark three-state cycle). Added a localized "Click to switch to {locale}" tooltip message.
- Redesigned the theme from Deep Navy & Gold to Forest & Copper: a warm forest-green primary with copper accents in light and dark modes, a gray-green neutral ramp, muted semantic colors, and an updated print palette.
- Switched the site fonts to self-hosted Lora for headings and IBM Plex Sans for body text (both variable, 400–700, with italics), plus IBM Plex Mono for code and BibTeX snippets. Inter and Georgia were removed.
- Rebuilt the CV page as a narrative academic portfolio: a new `cv` page type driven by a structured `content/cv.toml` with an academic profile, expandable appointments timeline, education, research project cards, publications (reusing `publications.bib`), teaching & supervision, grants & awards, academic service, and skills. Includes a sticky section index with scroll-spy, a print/PDF action, print-friendly styles, and i18n support via localized section headings. See `docs/cv.md` for the schema. The old `content/cv.md` text page was replaced by this content model.
- Added citation metrics from OpenAlex on the publications page: an author summary strip (citations, h-index, works count) and per-publication "Cited by" badges. Metrics are fetched at build time via `scripts/fetch-metrics.mjs` using the ORCID from `content/config.toml`, with a committed fallback in `data/openalex-metrics.json` so fresh clones and offline builds always have data. The deploy workflow now refreshes metrics weekly.
- Added optional Matomo analytics: configure `enabled`, `matomo_url`, and `matomo_site_id` in the new `[analytics]` section of `content/config.toml`. The standard Matomo JS tracker is embedded in `<head>` and a `<noscript>` tracking pixel is rendered at the end of `<body>` as a fallback for visitors with JavaScript disabled. Tracking is fully disabled (no tracker rendered) unless all values are set.
